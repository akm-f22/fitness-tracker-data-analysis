Project Overview
This project analyzes fitness tracker data to understand user behavior related to physical activity, sleep patterns, and BMI.
The goal is to extract insights that can help fitness applications improve user engagement and provide better health recommendations.
________________________________________

SQL (MySQL)
Power BI
________________________________________
The dataset contains user health metrics collected from a fitness tracker.
Files include:
•	Daily activity
•	Activity intensities
•	Sleep data
•	Weight and BMI logs

Final Business Recommendation

Based on this analysis, a fitness app could improve engagement by:

Users can be segmented into:
•	Highly active users (>10,000 steps)
•	Moderately active users (5,000–10,000 steps)
•	Low activity users (<5,000 steps)
Marketing campaigns can be personalized:
•	Active users → Promote advanced fitness plans or premium subscriptions
•	Moderate users → Encourage step challenges
•	Low activity users → Send motivational reminders

Physical activity contributes to improved sleep quality.
Marketing Strategy Campaign idea:
“Walk more, sleep better.”
This can encourage users to stay active.

Different BMI groups may require different health goals.
Marketing Strategy Personalized campaigns:
BMI Category - Campaign Focus
Underweight	- Nutrition & strength programs
Normal	- Maintain healthy lifestyle
Overweight	- Weight loss challenges
Obese	- Beginner fitness programs

Highly active users interact frequently with the app. These users are potential brand promoters.
Introduce:
•	Referral programs
•	Community challenges
•	Social sharing
Users who consistently track activity and health data may be more willing to pay for premium features. Highly engaged users are more likely to convert to paid subscriptions.
Offer premium features like:
•	Personalized coaching
•	Advanced analytics
•	Nutrition tracking
